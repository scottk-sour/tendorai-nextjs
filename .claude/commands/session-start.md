At the start of every new session:
1. Read CLAUDE.md in full.
2. Run `git branch` — confirm we are on main.
3. Run `git log --oneline -5` — show last 5 commits.
4. Run `git status` — show any uncommitted changes.
5. List the current nav items by reading the nav component.
6. Report any obvious issues before starting work.
Then ask: what would you like to work on today?
