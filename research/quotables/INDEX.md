# Quotables — Master Index

A running register of every batch generated by `/quotable-extractor`. Each batch contains 10 quotes (3 problem framing, 3 data findings, 2 solution clarity, 2 category positioning).

## Convention

- **One file per batch.** Filename: `YYYY-MM-DD-batch-NN.md` (zero-padded).
- **One INDEX update per batch.** Add a new row to the table below.
- **Status values:** `planned` (assigned to a channel but not posted), `used` (posted — note where), `reserve` (not yet assigned), `retired` (do not reuse — superseded or fact changed).
